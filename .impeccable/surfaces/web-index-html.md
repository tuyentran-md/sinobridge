# Surface: SinoBridge web demo (web/index.html)

Mode: operate. Audience: general readers and researchers in equal measure (owner-confirmed). Task: drop a Chinese file, connect a model (own key, Gemini free key first; local WebGPU fallback), translate, read side by side, export. Constraint: one working screen on desktop, no backend, key goes only to the chosen provider.

## Direction contract

THESIS: Translation as sơn mài: the Chinese source is the base coat and each finished passage is polished to reveal its translation in gold. Refuses the white single-accent dropzone page with stacked form cards.

OWN-WORLD: Lacquer browns own every surface (#140c0a page, #1b1210 rail, #22170f reader); cinnabar #c8402c only for the primary action and in-progress marks; gold #d9a94e only for finished translation; eggshell #f1e7d6 text. Be Vietnam Pro for UI and translation, Song-style CJK serif for Chinese.

STORY: The visitor sees where to drop a file, where to paste a key and what button translates, then watches passages turn gold and downloads EPUB or Word.

FIRST VIEWPORT: 54px top bar (seal + wordmark, document name, Hỏi đáp/GitHub). Left rail 330px: Tài liệu, Model (provider, key, model, target), cinnabar Bắt đầu dịch with inlay progress, Tải về. Right: the bilingual reader (source | spine | translation), or the welcome drop zone when empty.

FORM: assigned grounded candidate 6 of 7 (sơn mài lacquer); signature: khảm-tile progress inlay plus the gold polish reveal on each finished passage and spine mark. seed: none (unavailable)

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
