# Surface: SinoBridge web demo / Paper & Ink

Mode: operate. Audience: Chinese-book readers and researchers alike. Same workflow: file → provider → translate → read both languages → export.

## Design contract (owner correction, 2026-11-09)

DIRECTION: Bright Chinese watercolor reading room, not a generic AI dashboard and not the old dark lacquer concept. Warm paper (#faf9f4), muted green ink (#273b30), cinnabar seal/action (#a43e34), completion sage (#91a789).

COMPOSITION: White/cream paper with a faint ink landscape of mountains, bridge and bamboo **only in the empty welcome state**. Use an editorial left-aligned introduction and a solid-paper import surface; restrained thin rules in the 4-step rail. No cards inside cards or gratuitous glow.

RESPONSIVE: Working screen with independent rail and reader scrolling on desktop. Mobile stacks naturally without horizontal overflow.

READABILITY: Preserve source next to each translation, no background illustration behind active reading rows; easy-to-find model/key/target and export buttons. Dark mode secondary and usable.

FILE REFERENCE: `DESIGN.md` documents the current owner-accepted direction. The old sơn mài-only concept is superseded.
